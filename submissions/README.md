## 应用介绍（约 200 字，可作报名文案）

个人成长后台是一个面向新员工入职 90 天成长场景的工作台应用。它以明道云 HAP 工作表为唯一数据底座——入职任务、工具指南、测验题库、团队成员全部零代码管理，前端 React 工作台通过明道云开放 API 实时读写；AI 真实参与关键任务：一句话拆解出 3-6 条可执行子任务、上传参考图流式生成任务描述、一句话生成带间隔重复算法的学习模块。页面上的每一次点击都会真实写回明道云工作表，不是演示数据。

# 明道云搭建手册（后台数据底座）

> 目标：在你的明道云应用里建 6 张工作表 + 拿到 API 密钥。全程约 20 分钟。
> 应用入口：https://www.mingdao.com/app/977a582e-4874-4143-9676-e6310b9c1a17/6aaf7074f0138614495e4f75/

## 第 1 步：建 6 张工作表（10 分钟）

在你的应用里「新建 → 工作表」，逐张创建。**字段全部用「文本」类型**（API 写入零兼容问题；表单/看板等视图后续可再加）。

字段名必须与下表**完全一致**（服务端按字段名读写）：

| # | 表名 | 字段（逗号分隔，全为文本） |
|---|------|------|
| 1 | 工种角色 | 角色名称，入职周期周数，部门 |
| 2 | 入职任务 | 任务名称，任务描述，任务分类，任务状态，阶段，所属工种 |
| 3 | 工作工具 | 工具名称，工具分类，一句话说明，掌握程度，是否必须掌握，使用指南 |
| 4 | 知识测验题库 | 题目，正确答案，错误选项，解析 |
| 5 | 团队成员 | 姓名，职位，团队，负责领域，工位，一句话介绍，角色标签 |
| 6 | 工具教程 | 教程标题，所属工具，分类，难度，预计学习时长，是否必修，内容 |

提示：可以先用一张表试试「AI 创建工作表」（把上面一行字段清单发给它），再逐字段校对名称。

## 第 2 步：导入种子数据（5 分钟）

仓库 `mingdao-seed/` 下有 6 个 CSV（UTF-8，带 BOM，可直接导入）。

每张表：「…」菜单 → **从 Excel 导入** → 选择对应 CSV → 字段映射确认（CSV 列名与字段名一致，自动对上）→ 导入。

| CSV | 导入到 |
|-----|--------|
| `01-工种角色.csv` | 工种角色（4 行） |
| `02-入职任务.csv` | 入职任务（8 行，含未开始/进行中/已完成三种状态） |
| `03-工作工具.csv` | 工作工具（6 行，掌握程度为 0-1 小数） |
| `04-知识测验题库.csv` | 知识测验题库（5 题；错误选项用「、」分隔多个选项） |
| `05-团队成员.csv` | 团队成员（3 人） |
| `06-工具教程.csv` | 工具教程（4 篇） |

## 第 3 步：拿 API 密钥 + 表 ID（5 分钟）⭐ 关键

1. 进入应用 → 左下角「…」或应用设置 → **授权管理**（应用管理员可见）。
2. **新建授权密钥** → 得到 `AppKey` 和 `Sign`，先复制保存。
3. 打开该应用配套的 **API 开发文档**（授权管理页里有入口），找到每张工作表的：
   - **工作表 ID**（worksheetId，形如 `655c79...`）
   - 每张表**任一视图的视图 ID**（viewId，形如 `660a12...`）
4. 把 12 个值（6 表 ID + 6 视图 ID）+ AppKey + Sign 发给我（或填进 `server/.env`，格式见 `server/.env.example`）。

> 验证顺序：如果免费版没有「授权管理」入口 → 告诉我，这是当前最大风险点，需要换路径（组织级密钥或联系比赛方）。

## 第 4 步（我来做）：自定义页面嵌入

等 Zeabur 部署出 HTTPS 链接后：应用里「新建 → 自定义页面」→ 添加「嵌入 URL」组件 → 填链接 → 开「公开分享」。

## 字段类型备注

- 「任务状态」「任务分类」如果想改成单选/多选获得更好看视图：先把选项建全（任务状态：未开始/进行中/已完成），再告诉我，服务端可按控件类型传值；默认全文本最稳。
- 「掌握程度」保持文本，存 `0.95` 样式的小数（前端自动换算成 95%）。
